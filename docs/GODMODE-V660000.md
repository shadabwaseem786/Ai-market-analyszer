# V660000 — NLP/LLM Catalyst Intelligence + Reliability 3.0

Adds an NLP/LLM-ready catalyst pipeline with event classification, sentiment, uncertainty,
source reliability, novelty, contradiction detection, entity mapping, surprise and severity.

The included baseline uses transparent heuristics so it can run without an external LLM. Production
quality should augment this with a calibrated NLP/LLM provider, source-specific reliability priors,
and historical validation. No source is treated as truth solely because it is classified as reliable.
