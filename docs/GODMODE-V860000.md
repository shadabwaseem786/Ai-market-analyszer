# V860000 — News, Geopolitical, Macro & Event Intelligence

Adds normalized news/event ingestion, source credibility, duplicate-story clustering, event extraction,
sentiment/uncertainty, surprise detection, geopolitical risk, a dedicated Iran/Middle-East catalyst
layer, macro surprise and transmission channels, sector impact mapping, catalyst half-life, severity,
scenario analysis and event-to-F&O fusion.

Event signals are probabilistic and source-dependent; the Iran/Middle-East layer is an explicit
risk/catalyst framework, not a claim about future geopolitical events.
