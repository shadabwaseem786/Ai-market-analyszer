# V710000 — Portfolio Intelligence + Filtered Market Views

Adds portfolio heat, bounded position sizing, fractional Kelly helper, sector concentration,
options Greeks/stress interfaces and explicit universe filters.

UI change: indices, stocks, stock F&O and other instrument classes are no longer forced into one
combined view. A persistent filter bar provides All, Indices, Stocks, Stock F&O, Index F&O, Options,
Futures and ETFs. The selected filter persists locally.

Filters are presentation controls; portfolio risk and decision gates remain portfolio-aware.
